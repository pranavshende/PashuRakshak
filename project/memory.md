# Project Memory

PashuRakshak (“Animal Guardian”) is an offline-first Edge AI system for livestock disease detection.

## Current State
The project has successfully progressed through multiple development phases.
- **Completed**: Core Farmer Flow, Sync & Backend, Vet Routing & Admin Dashboard, ML Microservice, Realtime CI/CD.
- **Completed**: UI/UX Overhaul & Parity Tuning.
- **Completed**: Digital Twin & Recovery Monitoring features.
- **Completed**: Intelligence & Predictive Analytics (Surveillance Heatmap, Community Intelligence Feed).
- **Completed**: Smart Farm & Conversational AI (AI Vet Assistant, AI Farm Productivity Score, IoT Smart Livestock Monitor).

## Active Components
1. **Client (Mobile/Web)**: Located in `app/` and `Web/` using React Native / Expo and Vite respectively.
2. **Backend Services**: Express.js server located in `Backend/` with Prisma ORM connecting to Supabase Postgres.
3. **ML Microservice**: FastAPI server located in `Backend/mlservice/` handling fallback inference.
